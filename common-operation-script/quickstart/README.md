# Getting Started Guide

This guide walks you through functional development on your local machine. Start by cloning the [luther sandbox](https://github.com/luthersystems/sandbox) on GitHub and save your license file as `.luther-license.yaml` in that directory.

Then follow the steps in order:

1. [Local System Requirements](local-system-requirements.md): the tools to install.
2. [Run Your First Network](run-your-first-network.md): start the sandbox network.
3. [Add Your First Endpoint](add-your-first-endpoint.md): add an endpoint to the phylum.
4. [Update Your Data Model](update-your-data-model.md): add a field to the data model.
5. [Write Your First Unit Test](write-your-first-unit-test.md): test the change.

[Detailed Setup](detailed-setup.md) covers editor setup, formatting and the Go module settings.
